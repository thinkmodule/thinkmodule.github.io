KV-Cache Memory Footprint

KV = 2 × L × n_kv × d_head × S × B × b_kv

Factor 2 stores both Key & Value tensors across L layers. GQA shrinks n_kv by 4×–8×; MLA compresses KV into a shared low-rank latent vector.

Roofline Ceiling & Ridge Point

P(I) = min(P_peak, BW_hbm × I),   I* = P_peak / BW_hbm

When Arithmetic Intensity I < I* (e.g., Decode B=1 at ~1 FLOP/Byte), Tensor Cores stall waiting on HBM memory transfers regardless of peak TFLOPs.

PagedAttention (vLLM) Efficiency

Waste_paged ≤ B × (BlockSize − 1) / 2  (<4%)

Eliminates contiguous over-reservation by mapping non-contiguous 16-token physical GPU blocks through a per-sequence block table, unlocking 2×–4× larger batches.
